1 · Color Palette

The palette balances warm-neutral surfaces (inspired by aged paper and stone) with a muted sage green as the primary interactive accent. Charcoal anchors the sidebar and text hierarchy. All contrast ratios meet WCAG AA for text uses.

7 · Preview Canvas Panels

The right-side canvas is a dynamic panel that adapts to the current AI task. It supports three rendering modes:

ModeTriggerRenderer
Diagram ViewGenerate diagram requestMermaid.js / SVG output
Code Diff ViewCode refactor / analysisMonaco diff editor, read-only
Concept CardPractice / quiz requestStructured markdown card
Toolbar: Each canvas mode shows a floating top-right toolbar with Copy, Export (PNG/SVG/MD), Fullscreen, and a mode-switcher pill.
